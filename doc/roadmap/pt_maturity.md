# 成熟 PT 站能力差距清单

这份文档记录 NextPT 距离成熟 PT 站还需要补齐的产品能力。它不是当前迭代的全部计划，而是后续拆任务时的能力地图。

## 近期优先

1. **站点公告（已完成）**
   - 面向全站用户发布重要通知、规则调整、维护公告和活动说明。
   - 已归属 `site` 域，后台提供公告管理，登录首页展示公告并支持已读状态。
   - 当前保持轻量，只支持标题、正文、状态和发布时间，不引入置顶、高亮、可见范围和过期规则。

2. **站内消息与通知中心（已完成）**
   - 用于系统通知、管理操作结果、回复提醒、@ 提及、赞赏、举报处理结果、等级变化等。
   - 已归属 `site` 域，不与论坛私信或管理工单混用。
   - 已支持未读数、已读/全部已读、关联目标跳转，以及评论、回复、赞赏、举报处理、账号限制和等级变化通知。
   - `@` 提及和复杂通知聚合留到社区增强阶段。

3. **RSS 与订阅（MVP 已完成）**
   - 已支持按分类、关键词、优惠状态和数量生成种子 RSS 地址。
   - 已和 passkey、账号状态、RBAC、种子可见性以及私有种子下载联动。
   - 当前不保存订阅记录；收藏条件、自定义订阅管理和推送留到后续阶段。

4. **H&R / 保种考核（暂缓）**
   - 记录用户对种子的下载完成、做种时长、分享率和违规状态。
   - 需要和 Tracker、Accounting、Mod 联动。
   - MVP 可以先提供统计和后台查看，再逐步接入自动处罚。
   - 当前先通过站点分享率与现有权限体系引导用户，不进入近期开发。

5. **求种与续种请求（MVP 已完成）**
   - 已使用独立的 Catalog 请求资源，与论坛主题分离。
   - 已支持求种、续种、认领、放弃、提交、确认完成、取消和过期释放。
   - 已支持魔力奖励托管、完成发放、取消退款、评论、举报和站内通知。
   - 后续可按实际使用情况补充请求排序、Staff 管理视图和更细的反滥用策略。

6. **魔力商城（MVP 已完成）**
   - 商品通过 `economy.shop_products` 配置，类型由后端枚举并分派到独立履约逻辑。
   - 已支持商品列表、事务兑换、订单记录、魔力流水和后台配置。
   - 已支持邀请码、VIP 时长、入账上传量和入账下载量抵扣商品。

## 资源与发布

- **高级种子搜索与筛选（第二阶段已完成）**：已支持分类、分组标签、优惠、推荐、体积、发布时间、做种状态、常用排序，以及 IMDb、TMDB、豆瓣和 Bangumi ID 精确筛选；页面与 RSS 共用筛选模型。标签采用同组 OR、跨组 AND，并已接入发布、编辑、列表、详情和后台管理。
- **资源元数据增强（MVP 已完成）**：已支持 TMDB、IMDb、豆瓣和 Bangumi 身份绑定、跨来源补缺、评分快照、缓存，以及发布、编辑和详情展示。
- **MediaInfo / 截图 / 海报（暂缓）**：发布页支持上传或填写媒体信息，详情页更适合判断资源质量；图片存储与发布流程需要单独设计，后续再进入开发。
- **重复种子检测**：按 info_hash、标题规则、媒体元数据和文件结构降低重复发布。
- **上传审核区**：对低等级用户或敏感分类进入待审核状态，Staff 审核后公开。
- **标题与发布规则继续完善**：不同分类的 release fields、标题生成、必填校验和引导需要持续细化。

## 社区互动

- **用户公开主页**：展示分享数据、最近发布、论坛参与、徽章、加入时间等。
- **关注 / 屏蔽 / @ 提及**：提升社区互动效率，也需要通知中心承接提醒。
- **规则 / FAQ / Wiki**：可以先复用论坛只读节点，后续再考虑独立内容管理。
- **投票与活动**：用于站点活动、资源评选、规则意见征集。
- **论坛与评论赞赏统一体验**：当前已有通用 reward 方向，后续要覆盖更多目标类型并保持 UI 一致。

## 管理与运营

- **Staff 备注与风险画像**：管理组可以查看用户处罚、举报、作弊记录、邀请关系和内部备注。
- **申诉 / 工单**：用户对处罚、H&R、账号限制发起申诉，Staff 处理留痕。
- **批量管理操作**：批量移动主题、批量调整种子优惠、批量处理举报、批量用户限制。
- **完整邮件系统**：注册、找回密码、重要通知、站点公告邮件推送。
- **API Token 与自动化接口**：给高级用户或工具使用，配合权限和限流。
- **备份、维护模式、健康状态页**：方便站点维护和故障透明化。

## 账号与成长

- **自动升降级闭环**：角色规则、定时任务、处罚/恢复、日志和前端展示需要形成完整链路。
- **捐赠 / VIP / 徽章**：不作为普通等级，但可以参与用户权益、展示和升降级规则。
- **邀请链路强化**：区分站点级邀请、用户邀请、角色定向发放、过期与回收。
- **安全能力补充**：邮箱验证、两步验证、登录风险提示、异常设备管理可以放到后续阶段。

## 数据迁移与兼容

- **旧站迁移工具**：NexusPHP 等老站数据导入，包括用户、种子、评论、字幕、论坛、魔力和历史记录。
- **BBCode 兼容清理**：当前渲染以 Markdown 为主，BBCode 迁移只保留文本与基础语义，复杂样式逐步丢弃。
- **数据修复脚本**：早期开发阶段可以直接修 SQL，站点成熟后需要版本化迁移和修复脚本。

## 建议实施顺序

1. 上传审核区
2. 用户公开主页
3. Staff 备注与风险画像
4. 魔力商城更多商品履约

站点公告、通知中心、种子 RSS、求种与续种请求、高级种子搜索第二阶段、资源元数据增强和魔力商城 MVP 已完成。RSS 自定义订阅、MediaInfo / 截图和 H&R 暂缓。
